# T-WANA Battle Arena

A mobile-friendly browser-based 3D neon arena prototype built with Three.js.

## Play locally
Open `index.html` in a modern browser with an internet connection. Three.js is loaded from jsDelivr.

## Controls
- **Mobile:** left joystick to move; drag on the right side to rotate the camera.
- **Desktop:** WASD / arrow keys to move; drag on the right side of the screen to look around.
- Collect all 10 glowing crystals before the 90-second timer ends.

## Deploy free with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to publish. Your game URL will be:
   `https://ssp859326-ai.github.io/t-wana-battle-arena/`

No build step is required.
